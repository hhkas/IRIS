📑 COC(ICIGI) 대상 품목 — 자재별 확인 방법

수입 예정 자재가 COC 대상인지는 HS Code 기준으로 최신 ICIGI 품목 목록과 직접 대조해야 합니다. 아래 절차로 확인하시고, 대상 여부가 불확실하면 지정 발급기관(TÜV·Intertek 등)에 직접 문의하시기 바랍니다.
  1. 수입 자재의 HS Code(세번)를 확정한다 (품목분류 사전심사 활용 가능)
  2. 최신 ICIGI 대상품목 목록을 COSQC 또는 지정 발급기관에서 입수한다 (품목 목록은 수시 개정됨)
  3. HS Code 또는 품명으로 목록을 대조하여 대상 여부를 확인한다
  4. 대상이면 선적 전 지정 발급기관에 COC 신청 (인보이스·패킹리스트·시험성적서 필요)
  5. 비대상이어도 향후 목록 개정 가능성을 고려해 주기적으로 재확인한다
