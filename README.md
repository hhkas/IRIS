# IRIS — Iraq Regulatory, Import & Supply monitor

이라크의 **면세·관세·통관 제도, 환율, 수입 물류, 건설자재 시장** 변화를 추적하는 공개 정보 모니터입니다.
BNCP(Bismayah New City Project) 현장의 구매·통관·물류 담당자가 조달 일정과 비용 리스크를 판단할 때 참고하도록 만들었습니다.

- 사이트: https://hhkas.github.io/IRIS/
- 형태: 서버 없는 정적 웹페이지 (GitHub Pages) + 뉴스 자동 수집 (GitHub Actions)

> 브리핑은 조사 시점의 정리입니다. 이후 변동은 **정보원** 탭의 원문 출처에서 직접 확인하세요. "헤드라인 기준"으로 표시된 내용은 원문을 확인하지 못한 것입니다.

| 탭 | 내용 | 갱신 |

| 🔗 정보원 | 제도·관세, 통관·항만, 경제·환율, 건설자재·인증, 원자재·해상운임, 뉴스·분석, 한국 측 정보 출처 목록 | 수동 |

## 뉴스 자동 수집

- **실행**: 매일 UTC 03:00 (바그다드 06:00 / 한국 12:00). Actions 탭 → *Collect Iraq trade news* → **Run workflow**로 수동 실행도 가능합니다.
- **출처**: Google News RSS 검색과 매체 피드 13개
  - 관세·통관, 항만·물류(움카스르·호르무즈·국경), 경제·환율, 투자·면세, 자재·건설, 에너지·전력, 정세·보안, 종합(Iraq Business News, 한국어 뉴스)
  - 영어·아랍어·한국어 검색어 포함
- **정리**: 최근 30일 기사만 남기고, 제목 중복을 제거하고, 카테고리별 상한을 둬서 최대 120건까지 보관합니다. 디나르 재평가 루머 같은 노이즈 키워드는 제외합니다.
- **번역**: 제목을 MyMemory 무료 API로 한글 번역합니다(`title_ko`). 이미 번역한 기사는 다시 번역하지 않습니다. 하루 쿼터를 넘기면 원문 제목을 그대로 둡니다.
  - 쿼터를 늘리려면 저장소 **Settings → Secrets and variables → Actions**에 `MYMEMORY_EMAIL`을 등록합니다 (익명 약 5천 자/일 → 약 5만 자/일).
- **커밋**: 변경이 있을 때만 `iris-bot` 이름으로 `news: YYYY-MM-DD HH:MM UTC` 커밋을 남깁니다.

## 브리핑 갱신 방법

1. `index.html`의 핵심 지표, 종합 의견, 관찰 일정, 해당 주제 카드를 고칩니다.
2. 상단의 "브리핑 최종 갱신" 날짜와 카드의 갱신 배지를 바꾸고, 바뀌기 전 판단은 "이전 기록 보기"로 옮깁니다.
3. 커밋하면 1~2분 뒤 사이트에 반영됩니다.

**최근 뉴스** 탭의 "브리핑 갱신 요청 만들기"를 쓰면, 수집된 기사로 갱신 요청문을 만들 수 있습니다.

## 접근 제한

- 외부 사이트에서 링크나 임베드(iframe)로 들어오는 접속은 차단합니다.
- 주소 직접 입력, 즐겨찾기, 같은 `hhkas.github.io`의 다른 업무 툴에서 오는 링크는 허용합니다.
- 공개 저장소이므로 소스와 `news.json`은 누구나 볼 수 있습니다. **사내 기밀이나 개인정보는 넣지 마세요.** 브리핑은 공개 정보만으로 작성합니다.
